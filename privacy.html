AtomLab Uploader — Privacy Policy

Last updated: October 13, 2026

AtomLab Uploader is a private desktop tool operated by the owner of the @AtomLabScience YouTube channel. It is used only by that owner.

Data accessed

With the owner's consent, the tool uses Google OAuth to access the YouTube Data API with the scopes youtube.upload and youtube.force-ssl. It uses them only to upload the channel's own videos, set their title, description, tags and visibility, upload caption files, and check the upload's processing status.

Storage

The OAuth token is stored only on the owner's own computer, with file permissions restricted to the owner. Video IDs and publication status are stored in a local log on that computer. No data is sent to any server other than Google's.

Sharing

No Google user data is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.

YouTube's own terms apply: YouTube Terms of Service and Google Privacy Policy.
